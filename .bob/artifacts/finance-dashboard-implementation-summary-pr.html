What Was Built

Full-stack architecture
React 19 + TypeScript Vite 8 Express 5 proxy Zustand store TanStack Query v5

An Express server wraps yahoo-finance2 at two endpoints (GET /api/finance/:ticker/quote and /api/finance/:ticker/history?days=N), keeping Yahoo's API behind a CORS-safe proxy. The React SPA consumes it via a typed service layer.

Three Dashboard Views

Today

IBM featured card (enlarged, featured prop) above a grid of 4 competitor cards showing real-time price and daily change. A horizontal RankingChart orders all five tickers by intraday % move.

Last 7 Days

Summary grid with per-card 7-day period-change badge. A multi-line ComparisonChart plots all five closing-price series on shared axes.

Last Quarter (~90 days)

Summary grid with Quarter badge. An area-fill ComparisonChart for trend context, plus a RankingChart showing quarter-to-date % performance.
